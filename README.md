# Combination Space Explorer

An educational Python project for exploring combination spaces and
benchmarking different generation methods.

## Project status

Early development.

## Goals

- Generate combinations from configurable character sets
- Calculate the size of a combination space
- Compare different generation methods
- Measure execution time safely
- Explain why combination spaces grow exponentially

## Origin

This project was inspired by the brute-force demonstration from
[Lecture "Securing Accounts" of CS50's Introduction to Cybersecurity](https://cs50.harvard.edu/cybersecurity/notes/0/),
taught by David J. Malan.

The educational source code associated with the lecture is available in the
[dmalan/cybersecurity](https://github.com/dmalan/cybersecurity) repository.

This independent project aims to develop the original idea further by adding
configuration, benchmarking, safety limits, documentation, and tests. It is
not affiliated with or endorsed by Harvard University or CS50.
